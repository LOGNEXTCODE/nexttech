Novedades del Departamento IT
Este mes, tus correos viajan más seguros
Buenos días, Nexters. Desde hace unas semanas todos podéis poner etiquetas a vuestros documentos y correos. Este mes damos el siguiente paso: el sistema empieza a echaros un cable cuando enviáis información sensible fuera de LOGNEXT.
¿Qué es etiquetar? Poner un sello que dice cómo de sensible es lo que tienes entre manos. A partir de ese sello, el sistema sabe cómo cuidarlo. Cuatro niveles, en cristiano:
  • Público — puede verlo cualquiera, dentro o fuera. Una nota de prensa, un folleto.
  • Uso Interno — el día a día de casa. Un acta, una circular, el orden del día de una reunión.
  • Confidencial — cosas de cliente o de negocio que no deben salir sin control. Una propuesta, un informe de proyecto.
  • Muy Confidencial — lo más sensible. Contratos, datos personales delicados, credenciales.
¿Qué cambia este mes? Si envías algo etiquetado como Confidencial o Muy Confidencial a alguien de fuera, el sistema te avisará y te pedirá que confirmes el envío. Tranquilo: tu correo sale igualmente. No es un muro, es un cinturón de seguridad — un segundo para pensar "¿de verdad esto va fuera?".
⚠ Estás enviando información Confidencial a un destinatario externo. Revisa que sea correcto. Si necesitas continuar, indica el motivo. — Seguridad · LOGNEXT IT
¿Te ha llegado un aviso y no sabes si pasó algo? Si recibes un mensaje de Seguridad · LOGNEXT IT avisándote de una regla al enviar, que no cunda el pánico: tu correo sí se envió. Es un aviso informativo del sistema de etiquetado, no significa que el envío fallara ni que se rechazara.
Una de futuro: de momento la etiqueta la eliges tú, y el sistema solo te la sugiere — como un corrector, pero para la confidencialidad. Tú confirmas. Con el tiempo será un paso fijo de tu trabajo, pero para entonces ya lo harás sin pensar.

Operación Endgame derriba Amadey y StealC: 27 millones de credenciales recuperadas

T1x03: La extensión que no era lo que parecía
